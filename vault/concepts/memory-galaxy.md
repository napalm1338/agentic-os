# Memory Galaxy

Every memory the AI has, plotted as a 3D galaxy. Stars are notes,
constellation lines are links, brightness is recency. Spin it, zoom
it, click any star to read the source.

The data comes from this very vault plus the agents' `brain/` folder —
so the galaxy is the AI's mind, finally seeable. Belongs to
[[agentic-os]]; the voice assistant [[jarvis]] files memories here.
